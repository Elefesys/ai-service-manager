# M4 — выбор AI API для российского пилота
Дата исследования: **28 октября 2026**. Repository: Elefesys/ai-service-manager.
Статус: desk research / рекомендация для реализации, **не live benchmark**.
Текущая выдача: [M4_HANDOFF](../tasks/M4_HANDOFF.md).
Решение о минимальном объёме: [IMPL-004](../decisions/IMPL-004-m4-pilot-ai.md).

## Вывод

**PolzaAI — первый выбор для M4.** GPTunnel остаётся альтернативой, если Polza не
проходит короткий API-пробник или не может предоставить подходящий маршрут.
RouterAI интересен ценой, но имеет документированную неоднозначность ограничений
поставщика при резервных попытках; до её разрешения не считать его эквивалентной
заменой закреплённому маршруту.

Основания: низкие опубликованные цены сравнимых моделей, OpenAI-compatible API,
tools/JSON Schema, отдельные сведения о capabilities и поставщиках, запрет
неофициальных провайдеров по ключу, provider allowlist и учёт стоимости в рублях.
Это выбор наиболее подходящего первого кандидата по доступным сведениям.
Качество русского диалога, задержки, фактический счёт и соблюдение маршрута
под данным ключом ещё предстоит проверить; статус маршрута до этого EVAL_ONLY.

В исходной v0.28 уже был Polza-first (ADR259), GPTunnel — comparison.
Представление «GPTunnel уже доказанно лучший» не подтверждается каноном или
прочитанной передачей C0. Предыдущие предпочтения не заменяли сравнение.

## Как исследован рынок

Проверен широкий публичный срез **24 сервисов/платформ**, принимающих рубли
или предлагающих российский API-контур. Сначала наличие developer API,
затем возможности и цены; чат-подписки не подставлялись вместо API-тарифов.
Отраслевые каталоги использованы для обнаружения названий, выводы — по
сайтам/документации самих сервисов. Это не утверждение, что существует
проверенный полный реестр всех небольших реселлеров России.

Для ASM существенны: русский диалог и уточнения, работа с текущими фактами,
узкие tools, проверяемый JSON, будущий image input, bounded latency, расход
на успешный сценарий, прозрачность маршрута/хранения. Большое число моделей,
чат-интерфейс, генерация видео и обещанный маркетингом uptime не дают преимуществ
нашему пилоту сами по себе. Сравнимые замеры через ключи не выполнялись.

## Сравнение опубликованных цен

Рубли за **1 000 000** токенов; обычный короткий интерактивный запрос,
вход / выход, без batch/cache скидки. Значения зафиксированы при чтении
28.10.2026; страницы и конвертация валют могут меняться даже в течение дня.
Цена карточки/«от» не гарантирует стоимость нужного закреплённого поставщика.
Налоги/договорные скидки не реконструировались: итог проверяется по аккаунту
и списанию; ProxyAPI явно указывает НДС 5% в каталоге.

| Сервис | GPT-6 Luna, вход / выход | Gemini 3.8 Flash, вход / выход | Что учитываем |
|---|---:|---:|---|
| [PolzaAI](https://polza.ai/models/openai/gpt-6-luna) | **5,83 / 29,14** | **43,72 / 218,60** | Публичная карточка; [Gemini](https://polza.ai/models/google/gemini-3.8-flash). Точный официальный upstream/цена — из каталога ключа |
| [RouterAI](https://routerai.ru/models/openai/gpt-6-luna) | 10 / 52 | 78 / 392 | Минимальный endpoint для короткого контекста; [Gemini](https://routerai.ru/models/google/gemini-3.8-flash); routing caveat ниже |
| [СОЮЗ](https://souz.ai/models/gpt-6-luna) | от 10,80 / 54 | — | Дешёвый канал green; названия каналов сами не устанавливают upstream/retention |
| [Neurly](https://www.neurly.ru/models) | 13,15 / 65,72 | — | Обычный Luna, не Pro и не batch; собственный расчётный курс сервиса |
| [GPTunnel](https://www.gptunnel.ru/ru/prices) | **20 / 100** | **150 / 750** | Текущая акция −50%; без неё 40/200 и 300/1500; исходная единица на странице 1K |
| [AITUNNEL](https://aitunnel.ru/models/gpt-6-luna) | 20 / 100 | — | Базовый короткий запрос; 2/1M — чтение cache, не обычный ввод |
| [ProxyAPI](https://proxyapi.ru/models/browse) | 30 / 150 | — | Каталог с НДС; не путать с Luna Decisions |
| [PlusVibeAPI](https://plusvibeapi.ru/model/gpt-6-luna) | 3 / 19,07 (Cx); 0,72 / 3,56 (Purple) | — | Cx прямо предупреждает об игнорировании max_tokens; Purple публикует 89,42% доступности за 7 дней, не наш замер |
| [Zerocoder](https://zerocoder.com/ru/ai-tools/gpt-api) | 2,20 / 11 | — | **Минимум 0,50 ₽ за вызов**: номинальная токенная цена не цена короткого диалога |

«—» означает, что в этой таблице не фиксировали сопоставимую цену, а не отсутствие
модели. VseGPT исключён из числового сравнения: заголовок официальной таблицы говорит
«рубли за 1000 символов», а описания ряда моделей — о биллинге по токенам
поставщика. Значения 0,033/0,165 для Luna нельзя без уточнения единиц выдавать за
33/165 ₽ на миллион токенов. Прямое открытие каталога инструментом также давало
timeout, поисковая копия доступна; это не замер API uptime.

**Иллюстрация, не прогноз счёта:** 1 000 model calls по 2 000 входных и
400 выходных токенов без reasoning/cache/tools дают по этим Luna-тарифам:
Polza **23,32 ₽**, RouterAI **40,80 ₽**, GPTunnel/AITUNNEL **80 ₽**,
ProxyAPI **120 ₽**; Zerocoder — **не менее 500 ₽** из-за минимума за каждый вызов. Полный диалог содержит несколько calls,
повторяемую историю, tool results и иногда оплачиваемые неудачные попытки.
По опубликованной цене Polza дешевле GPTunnel примерно в **3,4 раза** для
этих двух моделей. Это не доказательство одинакового качества/скорости/маршрута.
Polza не объявляется абсолютным минимумом рынка: PlusVibe публикует ещё меньшие
тарифы, но с существенными оговорками для выбранных каналов. Их собственные
метрики не сравниваются с нашими отсутствующими замерами других API. На небольшом
объёме управляемость и стоимость разработки важнее экономии десятков рублей.

## Данные, маршруты и обнаруженные оговорки

- [Polza unofficial providers](https://polza.ai/docs/gaidy/unofficial-providers):
  по документации они выключены по умолчанию, разрешаются отдельно для ключа,
  имеют риски хранения, поведения и доступности. Для ASM оставить
  `allowUnofficialProviders=false`; наличие дешёвой карточки не означает
  допуск любого её upstream. Каталог ключа с `include_providers=true` даёт
  `is_unofficial`; актуальные capabilities запрашиваются отдельно.
- [Polza provider selection](https://polza.ai/docs/gaidy/provider-selection)
  описывает `provider.only`, `allow_fallbacks=false`, ценовой ceiling и provider
  в ответе. M4 закрепляет один допустимый endpoint; тайное переключение не
  становится разрешённым из-за ошибки. Значения upstream IDs берутся из
  текущего каталога, не угадываются по имени модели.
- [Polza privacy](https://polza.ai/docs/osobennosti/privacy) заявляет отсутствие
  хранения текстовых запросов/ответов на самом gateway, но прямо описывает
  передачу внешним поставщикам, иногда цепочкой, с различным retention.
  Это заявление сервиса, не наш аудит и не гарантия обработки в РФ.
  [Оферта](https://polza.ai/documents/user-agreement) и
  [политика](https://polza.ai/documents/privacy-policy) не закрывают автоматически
  допустимость персональных клиентских данных нашего продукта.
- RouterAI в [одной инструкции](https://routerai.ru/docs/guides/overview/provider-selection)
  описывает only как ограничение, но отдельно предупреждает о возможной резервной
  попытке вне списка и выделяет country как всегда соблюдаемый фильтр.
  Это противоречие важно именно ASM: нужна ясная гарантия approved upstream,
  не только совпадение страны. До письменного уточнения маршрут не одобрять.
- [GPTunnel structured output](https://docs.gptunnel.ru/api/chat-completions/)
  различает нативный schema-режим и best-effort json_object для Claude;
  для Gemini/других моделей параметры передаются upstream. OpenAI-compatible
  форма сама по себе не подтверждает точность tools/JSON каждой модели.
- [Polza usage](https://polza.ai/docs/osobennosti/usage) даёт cost_rub и
  разбивку usage. Сохранять фактическую валюту/единицы/ценовой snapshot.
  Не пересчитывать reasoning двойным счётом и не выдавать отсутствующую стоимость
  после timeout за ноль. Каталожная оценка и подтверждённое списание различаются.

Перед передачей реальной переписки нужен короткий route record: договорная
доступность для нашего использования, gateway/upstream/модель, обработка/retention,
разрешённые классы данных и fallback. Российская оплата не доказывает
российское размещение. До этого — synthetic/de-identified TEST с явной политикой;
простая маскировка телефонов не гарантирует обезличивание свободного текста.
Это конкретная граница данных, не поручение строить compliance-платформу.

## Начальные модели и короткая проверка

Два кандидата достаточны:
- `openai/gpt-6-luna` — дешёвый кандидат основного диалога/уточнений/JSON;
- `google/gemini-3.8-flash` — сравнение качества и будущего image input.

Ни один не объявляется победителем по качеству без теста. В runtime сначала
одна прошедшая модель; разные задачи могут позже получить другие профили.
Не добавлять классификатор, summary-модель и «умную» модель на каждый Turn.
Если оба не подходят, испытать один обоснованный следующий кандидат, а не весь
каталог. Уточнение отсутствующей цены/правила решается вопросом/мастером.

M4.2-PROBE на выделенном ограниченном ключе:
1. Получить ID, официальный upstream, capabilities/tools/strict-schema, цены,
   ограничения и настройку неофициальных провайдеров.
2. Проверить JSON и хотя бы один реальный цикл tools→tool result→ответ; image
   capability — на нескольких разрешённых synthetic images для раннего риска M5.
3. Прогнать ориентировочно 20–30 коротких русских сценариев: уточнения, неизвестные
   услуги/цена, смена контекста, owner facts, prompt injection, handoff, отказ API.
   Повторить критические/вариативные случаи; не обещать статистическую гарантию
   по маленькой выборке.
4. Сравнить корректность и стоимость завершённого сценария, число calls,
   observed p50/p95 с размером выборки, ошибки и списания. Сначала пригодность,
   затем минимальная стоимость среди пригодных. Критерии фиксируются до прогона.
5. Сохранить короткий итог с exact route/prompt/schema revisions.
   API-key, реальные сообщения и частные ID в Git/артефакты не публиковать.

Первая проверка одного выбранного агрегатора не требует оплаты аккаунтов всех
24 сервисов. GPTunnel/другой gateway получает live сравнение только при конкретной
проблеме или существенной неопределённости Polza, по тому же набору.
Публичные цены поддерживают выбор Polza для старта; live PASS/OPEN-074/075 не
подменяются этим документом.
