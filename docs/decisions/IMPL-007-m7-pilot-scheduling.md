[Очередь и критерии M7](../tasks/M7_HANDOFF.md). Основание решения — ADR-015/016, 082–086, 177, 201/202, 263, 266 и 268. ## Принятые условия реализации и приёмки

- Источник минут и режима предоплаты — именно `QuoteMaterial.occupied_minutes`, `duration_reference_id` и версия `deposit` из принятого Quote. Это уже время, занимаемое сеансом; внешние буферы до/после добавляются один раз. Клиент видит начало, окончание и часовой пояс; мастер также видит технически занятый интервал. Невозможно доказать полномочия, текущую пригодность или длительность — ничего не обещать, показать причину.
- Публично показанный вариант не удерживает место. Выбор конкретного доставленного варианта — отдельное намерение, не согласие с ценой и не выбор агента. Каждая операция связана с клиентом, бизнесом, диалогом, сеансом и целью; непрозрачный ID или короткая метка не заменяет авторизацию. Уточнение/повтор/чужая работа не должны поменять занятость. Один активный Hold либо Appointment для логического сеанса; два разных сеанса клиента не сливаются.
- Вариант для переноса строится для **конкретной текущей записи**: при предварительном поиске можно не вычитать только её собственную занятость. Окончательная замена проверяет остальных и блокировки в БД. Старая запись становится CANCELLED, новая — CONFIRMED, связана с предыдущей; ошибка оставляет старую целиком. Смена рабочих часов/выходного, пересекающая защищённый интервал, не должна тайно отменить обещание: для пилота отклонить конфликтующую операционную правку, показать владельцу затронутые объекты, сначала явно разрешить конфликт. Новая версия политики действует на новые предложения; действующие удержания не лишаются обещанного срока без явного действия. Подтверждённые записи не пересчитываются.
- Для локального времени: явная IANA-зона бизнеса, недельные интервалы + исключения по локальной дате; конкретные начала/концы — абсолютные instants. Работаем полуоткрытыми интервалами `[start,end)`. Несуществующий местный старт при весеннем переводе пропускается. При осеннем переводе для каждого подходящего абсолютного старта показываем местное время с его UTC-смещением. Два разных старта с одинаковым временем на часах различимы при выборе. Длительность — реальные прошедшие минуты, не разность цифр на часах. Сроки сверять по времени БД после ожидания блокировки; в точности на `expires_at` удержание уже недействительно. Подробнее: [PostgreSQL 18, интервалы и исключения](https://www.postgresql.org/docs/18/rangetypes.html#RANGETYPES-CONSTRAINT), [текущее время транзакции и реальное время](https://www.postgresql.org/docs/18/functions-datetime.html#FUNCTIONS-DATETIME-CURRENT).
- Сохраняются IMPL-006, проверки прав клиента/мастера, режим HUMAN, защита от устаревших worker и UNKNOWN/no-resend. Отдельный версионируемый контракт scheduling-намерений только после доменных команд. C0 может заменить предлагаемый способ меньшим рабочим вариантом: привести конкретный конфликт и источник, назвать видимый результат и сохранившуюся гарантию, явно записать решение. Снятие гарантии или расширение пилота — отдельное решение владельца.
